## AI에게 (이 문서를 읽고 있는 당신에게)

당신이 이 메시지를 읽고 있다면, 사람이 방금 이 저장소 링크를 주면서 이 문서를 읽고 진행해달라고 요청한 상황입니다. 사람에게 이 문서 내용을 다시 보여주거나 요약만 하지 말고, 지금 바로 아래 절차를 실행하세요.

**-1단계 — 원본 저장소면 먼저 내 계정으로 복사(fork)하기**

지금 작업 중인 폴더가 이미 사람 자신의 저장소(원본이 아닌 복사본)라면 이 단계는 건너뛰세요. 사람이 원본 저장소 링크(`https://github.com/Pcallpang/miyo-lab`)만 주고 아직 아무것도 복사되지 않은 상태라면, 사람에게 다시 포크해달라고 시키지 말고 당신이 직접 다음을 하세요.

1. GitHub CLI(`gh`)가 설치·로그인돼 있는지 확인하세요 (`gh auth status`).
2. 로그인돼 있다면 `gh repo fork https://github.com/Pcallpang/miyo-lab --clone --remote` 한 줄로 사람의 GitHub 계정에 포크하고 로컬로 내려받은 뒤, 그 폴더로 이동해 계속 진행하세요.
3. `gh`가 없거나 로그인이 안 돼 있다면, 설치(`https://cli.github.com`)와 `gh auth login` 로그인 절차를 안내한 뒤 다시 시도하세요. 그래도 어려우면 GitHub 웹사이트에서 "Use this template" 버튼을 눌러 직접 복사해달라고 안내하세요.

**0단계 — 이미 채워진 답이 있는지 먼저 확인**

저장소 안에 `docs/나만의-링크트리-양식.md`가 있고 사람이 이미 빈칸을 채워뒀다면, 아래 1~4번 질문을 다시 묻지 말고 그 파일 내용을 그대로 답으로 사용해 2단계로 넘어가세요.

**1단계 — 질문하기 (양식이 비어 있거나 없을 때만)**

바로 코드를 고치기 전에 먼저 사람에게 아래를 채팅으로 물어보세요. 필수 항목(1~4)만 먼저 물어보고, 선택 항목(5~11)은 "이런 것도 있는데 쓰시겠어요?" 식으로 가볍게 물어본 뒤 원하지 않으면 바로 넘어가세요.

필수

1. 표시 이름: DoRms 교사 OOO에서 OOO에 들어갈 이름
2. 첫 화면 소개 문구
3. 왼쪽 아래 파도타기 목록 첫 번째 항목에 들어갈 `도름스 커뮤니티 나의 활동` 링크 주소(URL)
4. 원하는 색감 (따뜻한 크림 / 차분한 파스텔 / 밝은 교실톤 / 진한 대비 중 하나. 각 색상 코드는 `docs/나만의-링크트리-양식.md` 맨 아래 "AI 참고용 색상표"에 있습니다)

선택

5. 자기소개 섹션 (소개 글 / 하고 있는 일들 목록 / 연락처)
6. 게시판 탭에 올릴 앱·글 링크
7. 사진첩 사진 (파일은 미리 `public/assets/`에 넣어달라고 안내)
8. 왼쪽 아래 파도타기 목록에 (도름스 활동 링크 외에) 추가로 넣을 링크
9. 미니홈피 배경음악 (유튜브 영상 링크와 곡별 시작 지점)
10. 방명록 예시 글
11. 방명록·방문 수를 실제로 움직이는 Firebase 연결 여부 (직접 Firebase 프로젝트를 만들거나 키를 발급할 수는 없으니, 필요하면 사람이 만들고 `.env.local`에 값을 넣도록 안내만 합니다)

연재물(미요툰) 탭은 묻지 마세요. `src/config/miyotoon.ts`의 `episodes`는 원 저작자의 개인 만화이니 기본적으로 비워 두세요(탭이 자동으로 숨겨집니다). 사람이 먼저 자기 연재물을 넣고 싶다고 하면 그때만 채우세요.

**2단계 — 코드 반영**

답을 받은 뒤 `src/config/linktree.ts`, `src/config/theme.ts`(연재물을 쓰기로 했다면 `src/config/miyotoon.ts`도)를 수정하세요. 왼쪽 아래 파도타기 목록의 첫 번째 항목인 `도름스 커뮤니티 나의 활동`은 유지하세요. 이 템플릿에는 여러 링크를 모아 보여주는 메인 링크 카드 목록 기능이 없으니 다시 만들지 마세요. 선택 기능을 쓰지 않기로 했다면 해당 배열은 빈 상태로 두세요. 공개 저장소에 개인정보, 비공개 링크, API 키, 환경변수, DoRms 본 서비스 내부 자산은 넣지 마세요.

**3단계 — 확인**

수정 후 `npm run build`로 오류 없는지 확인하고 결과를 사람에게 알려주세요.
