## AI에게 (이 문서를 읽고 있는 당신에게)

당신이 이 메시지를 읽고 있다면, 사람이 방금 이 저장소 링크를 주면서 이 문서를 읽고 진행해달라고 요청한 상황입니다. 사람에게 이 문서 내용을 다시 보여주거나 요약만 하지 말고, 지금 바로 아래 절차를 실행하세요.

**0단계 — 이미 채워진 답이 있는지 먼저 확인**

저장소 안에 `docs/나만의-링크트리-양식.md`가 있고 사람이 이미 빈칸을 채워뒀다면, 아래 1~7번 질문을 다시 묻지 말고 그 파일 내용을 그대로 답으로 사용해 2단계로 넘어가세요.

**1단계 — 질문하기 (양식이 비어 있거나 없을 때만)**

바로 코드를 고치기 전에 먼저 사람에게 아래를 채팅으로 물어보세요.

1. 표시 이름: DoRms 교사 OOO에서 OOO에 들어갈 이름
2. 첫 화면 소개 문구
3. 최상단 `도름스 커뮤니티 나의 활동` 탭에 넣을 링크들
4. 외부 링크: 네이버 블로그, 인스타그램, 카카오톡, 자료 모음 등
5. 탭 안쪽에 묶을 내부 링크와 각 설명
6. 원하는 색감 (따뜻한 크림 / 차분한 파스텔 / 밝은 교실톤 / 진한 대비 중 하나. 각 색상 코드는 `docs/나만의-링크트리-양식.md` 맨 아래 "AI 참고용 색상표"에 있습니다)
7. 쓰고 싶은 아이콘

**2단계 — 코드 반영**

답을 받은 뒤 `src/config/linktree.ts`와 `src/config/theme.ts`를 수정하세요. 첫 번째 탭 `도름스 커뮤니티 나의 활동`과 `/assets/dorms-community.png`는 유지하세요. 공개 저장소에 개인정보, 비공개 링크, API 키, 환경변수, DoRms 본 서비스 내부 자산은 넣지 마세요.

**3단계 — 확인**

수정 후 `npm run build`로 오류 없는지 확인하고 결과를 사람에게 알려주세요.
